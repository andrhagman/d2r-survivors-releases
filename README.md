# D2R Survivors downloads

[Download releases](https://github.com/andrhagman/d2r-survivors-releases/releases)

This repository hosts public mod update downloads. Development source remains
in a separate private repository. No GitHub sign-in is needed to download these
assets, and no Blizzard game files or player saves are distributed here.

**Development preview:** the current Amazon / Act I survival prototype is still
under in-game testing. A complete first-install GUI installer is not available.
The release ZIP updates an already prepared D2R Survivors runtime; it is not a
standalone game or a replacement for owning Diablo II: Resurrected.

The supported D2R executable version is listed in each release. Launch through
the installed **D2R Survivors** shortcut to check for newer mod versions. Updates
preserve existing saves and live settings. The launcher can play the installed
version when the update server is unavailable, subject to game compatibility.

Release assets contain our launcher, update helper, gameplay plugin, default
settings and third-party notices. They do not contain D2RLoader, extracted game
tables, game binaries or graphics. Those remain local installation inputs.
